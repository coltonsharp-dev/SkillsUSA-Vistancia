12
Factor the expression
\(2x^2 + x - 10\)
1 Identify a, b, and c

Write the expression in standard form \(ax^2 + bx + c\) and pull out each coefficient:

\[a = 2, \quad b = 1, \quad c = -10\]
2 Compute the product \(a \cdot c\)

Multiply the leading coefficient by the constant:

\[a \cdot c = 2 \times (-10) = -20\]

We need two integers that multiply to \(-20\) and add to \(b = 1\).

3 Find the factor pair

List factor pairs of \(-20\) and check which pair sums to \(1\):

  • \((-4) \times 5 = -20\) and \(-4 + 5 = 1\) ✓

The pair is \(-4\) and \(5\).

4 Rewrite the middle term

Replace \(+x\) with \(5x - 4x\) using the pair found above:

\[2x^2 + 5x - 4x - 10\]
5 Factor by grouping

Group the first two and last two terms, then factor each group:

\[(2x^2 + 5x) + (-4x - 10)\]
\[x(2x + 5) - 2(2x + 5)\]

Both groups share the binomial factor \((2x + 5)\). Factor it out:

\[(x - 2)(2x + 5)\]
🎯
Final Answer
\(2x^2 + x - 10 = (x - 2)(2x + 5)\)
✔ Verify by FOIL

\((x - 2)(2x + 5) = 2x^2 + 5x - 4x - 10 = 2x^2 + x - 10\) ✓

13
Factor the expression
\(3x^2 + 17x - 6\)
1 Identify a, b, and c
\[a = 3, \quad b = 17, \quad c = -6\]
2 Compute the product \(a \cdot c\)
\[a \cdot c = 3 \times (-6) = -18\]

We need two integers that multiply to \(-18\) and add to \(b = 17\).

3 Find the factor pair

List factor pairs of \(-18\) checking which sums to \(17\):

  • \((-1) \times 18 = -18\) and \(-1 + 18 = 17\) ✓

The pair is \(-1\) and \(18\).

4 Rewrite the middle term

Replace \(17x\) with \(18x - x\):

\[3x^2 + 18x - x - 6\]
5 Factor by grouping
\[(3x^2 + 18x) + (-x - 6)\]
\[3x(x + 6) - 1(x + 6)\]

Factor out the common binomial \((x + 6)\):

\[(3x - 1)(x + 6)\]
🎯
Final Answer
\(3x^2 + 17x - 6 = (3x - 1)(x + 6)\)
✔ Verify by FOIL

\((3x - 1)(x + 6) = 3x^2 + 18x - x - 6 = 3x^2 + 17x - 6\) ✓

15
Factor the expression
\(5x^2 - 13x - 6\)
1 Identify a, b, and c
\[a = 5, \quad b = -13, \quad c = -6\]
2 Compute the product \(a \cdot c\)
\[a \cdot c = 5 \times (-6) = -30\]

We need two integers that multiply to \(-30\) and add to \(b = -13\).

3 Find the factor pair

List factor pairs of \(-30\) and check which pair sums to \(-13\):

  • \((-15) \times 2 = -30\) and \(-15 + 2 = -13\) ✓

The pair is \(-15\) and \(2\).

4 Rewrite the middle term

Replace \(-13x\) with \(-15x + 2x\):

\[5x^2 - 15x + 2x - 6\]
5 Factor by grouping
\[(5x^2 - 15x) + (2x - 6)\]
\[5x(x - 3) + 2(x - 3)\]

Factor out the common binomial \((x - 3)\):

\[(5x + 2)(x - 3)\]
🎯
Final Answer
\(5x^2 - 13x - 6 = (5x + 2)(x - 3)\)
✔ Verify by FOIL

\((5x + 2)(x - 3) = 5x^2 - 15x + 2x - 6 = 5x^2 - 13x - 6\) ✓

16
Factor the expression
\(2x^2 - 7x - 9\)
1 Identify a, b, and c
\[a = 2, \quad b = -7, \quad c = -9\]
2 Compute the product \(a \cdot c\)
\[a \cdot c = 2 \times (-9) = -18\]

We need two integers that multiply to \(-18\) and add to \(b = -7\).

3 Find the factor pair

List factor pairs of \(-18\) checking which sums to \(-7\):

  • \((-9) \times 2 = -18\) and \(-9 + 2 = -7\) ✓

The pair is \(-9\) and \(2\).

4 Rewrite the middle term

Replace \(-7x\) with \(-9x + 2x\):

\[2x^2 - 9x + 2x - 9\]
5 Factor by grouping
\[(2x^2 - 9x) + (2x - 9)\]
\[x(2x - 9) + 1(2x - 9)\]

Factor out the common binomial \((2x - 9)\):

\[(x + 1)(2x - 9)\]
🎯
Final Answer
\(2x^2 - 7x - 9 = (x + 1)(2x - 9)\)
✔ Verify by FOIL

\((x + 1)(2x - 9) = 2x^2 - 9x + 2x - 9 = 2x^2 - 7x - 9\) ✓

18
Factor the expression
\(3x^2 - 5x - 28\)
1 Identify a, b, and c
\[a = 3, \quad b = -5, \quad c = -28\]
2 Compute the product \(a \cdot c\)
\[a \cdot c = 3 \times (-28) = -84\]

We need two integers that multiply to \(-84\) and add to \(b = -5\).

3 Find the factor pair

This one takes a bit more searching. List factor pairs of \(-84\):

  • \((-14) \times 6 = -84\) and \(-14 + 6 = -8\) ✗
  • \((-12) \times 7 = -84\) and \(-12 + 7 = -5\) ✓

The pair is \(-12\) and \(7\).

4 Rewrite the middle term

Replace \(-5x\) with \(-12x + 7x\):

\[3x^2 - 12x + 7x - 28\]
5 Factor by grouping
\[(3x^2 - 12x) + (7x - 28)\]
\[3x(x - 4) + 7(x - 4)\]

Factor out the common binomial \((x - 4)\):

\[(3x + 7)(x - 4)\]
🎯
Final Answer
\(3x^2 - 5x - 28 = (3x + 7)(x - 4)\)
✔ Verify by FOIL

\((3x + 7)(x - 4) = 3x^2 - 12x + 7x - 28 = 3x^2 - 5x - 28\) ✓
